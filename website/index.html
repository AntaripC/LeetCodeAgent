1. Two Sum

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.
Algorithmic Strategy: Single-pass hash map algorithm stores visited numbers with their index. For each number x, we look up whether (target - x) already exists in O(1) time.

Key Innovations

Engineered Specifically for LeetCode

Traditional AI chatbots force you to copy-paste back and forth. LeetCode AI Copilot integrates directly into the page DOM and Monaco code editor.

Frontier Reasoning Models

Powered by Google Gemini 4 Argon, OpenAI GPT-6 Astra, and GPT-6.1 Sol. Analyzes algorithmic constraints, guarantees optimal time/space complexity, and avoids brute-force traps.

Native Monaco Editor Bridge

Direct script-injection bridge into LeetCode's active Monaco Editor instance. Injects code cleanly while preserving full undo/redo history (Ctrl+Z) without breaking page state.

Zero-Secret Local Proxy

Want 100% key security? Run the built-in standalone Node proxy (server/local-backend.mjs). Your API credentials never touch Chrome extension storage.

Overwrite Protection & Diff

Never accidentally wipe out your code. If the editor contains your existing implementation, the Copilot triggers an interactive diff review before replacing.

Spending Safeguards

Set configurable daily request caps and prompt confirmation alerts before calling high-cost reasoning models. Protects your wallet from unexpected API charges.

Dual DOM & GraphQL Parser

Resilient against LeetCode front-end redesigns. Scrapes DOM selectors first, and gracefully falls back to the official LeetCode GraphQL schema to fetch clean problem statements.

Get Started

Install in Under 60 Seconds

Download the extension bundle and load it into Google Chrome or any Chromium browser (Brave, Edge, Arc, Opera).

1

Download Package

Click the download button below to get leetcode-copilot-extension.zip. Unzip the archive into any folder on your computer.

2

Enable Developer Mode

Open Google Chrome and navigate to chrome://extensions. Toggle the Developer mode switch in the top-right corner.

3

Load Unpacked

Click the Load unpacked button on the top-left, and select the unzipped directory containing manifest.json.

4

Open LeetCode

Open any problem on leetcode.com/problems/..., click the Copilot icon in your toolbar, and generate your first solution!
